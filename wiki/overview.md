# LLM Wiki Overview

## 현재 범위

LLM의 핵심 구조, 학습·정렬, 추론, 검색·에이전트 활용, 모델과 논문을 다룬다.

## 현재 상태

- 기본 폴더 구조와 운영 규칙을 생성했다.
- 아직 원본 자료를 ingest하지 않았다.
- 첫 번째 자료를 추가한 뒤 페이지 분류와 템플릿을 조정한다.
